# Brand context — CometChat (default)

Default brand for relevance judgement, internal links, and the meta suffix. Override if the user says
the page is for a different property.

## Product

**CometChat** is a chat & calling SDK/API developers drop into web and mobile apps — one-to-one and
group **messaging**, **voice/video calling**, and **moderation/AI** features, with UI Kits and SDKs
for React, React Native, Flutter, iOS/Android, Angular, JavaScript, and more.

## Audience (ICP)

Developers and product/eng leaders building in-app chat, live video, dating, social, community,
marketplace, healthcare, gaming, or support experiences. Briefs and meta should speak to *building*
(implementation, SDKs, architecture) and *evaluating* (comparisons, pricing, alternatives).

## Competitors (read SERPs against these; never position as a CometChat property)

Sendbird, Stream (GetStream), PubNub, Twilio (Conversations / Video), Ably, ZEGOCLOUD, Agora,
MirrorFly, TalkJS, Firebase (as a build-your-own alternative). A SERP dominated by these high-DR
domains usually means **Needs links / Hard** winnability.
